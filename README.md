\# TrustLayer



Escrow payment backend built with Django REST Framework, PostgreSQL, Redis, and Docker.



\## Features

\- M-Pesa STK Push integration via Daraja API

\- Idempotent webhook callback handling

\- PostgreSQL transaction safety with atomic operations

\- Containerized with Docker Compose

\- LDAP authentication ready



\## Stack

Python, Django, PostgreSQL, Redis, Docker, M-Pesa Daraja API



\## Architecture

Service layer separating API, business logic, and database access.
